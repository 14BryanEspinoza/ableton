# 🎛️ Ableton UI - Frontend Practice

Este proyecto es una práctica de maquetación frontend basada en el estilo visual del sitio oficial de **Ableton**, la empresa detrás de Live, Push y otros productos musicales. El objetivo fue poner en práctica HTML y CSS creando una interfaz limpia, moderna y responsiva.

---

## 📌 Descripción

El sitio web presenta una interfaz ficticia con una navegación tipo Ableton, acompañada de secciones informativas, imágenes, videos y un footer con múltiples enlaces. Es ideal para entrenar habilidades de diseño web, responsive layout, y estructura semántica con HTML.

---

## 🧪 Tecnologías usadas

- HTML5
- CSS3
- Flexbox
- Base64 para algunos íconos
- Inspiración visual: [Ableton.com](https://www.ableton.com)
